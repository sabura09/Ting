Build your own AI SaaS faster — with AI Suite. Perfect for startups, internal tools, admin panels, chat interfaces, and AI workflows.

AI Suite is a production-ready, full-stack AI SaaS Platform built with the latest Next.js 18 (App Router), Tailwind CSS, and Google Gemini AI.

Stop paying for dozens of separate AI tools. AI Suite combines 100+ powerful AI applications into one seamless dashboard. It features a robust Role-Based Access Control (RBAC) system, allowing you to manage users and subscription plans dynamically.

Top Features

AI Voice Calling Agent

To automate high-speed outbound lead qualification and deliver real-time transcripts directly to your dashboard, freeing you to focus 100% on closing qualified deals and No more dead dialing: The AI reaches, screens, and filters prospects. Built using Twilio voice webhook integrations with Amazon Polly Neural TTS and Gemini conversational systems.

AI Logo Architect

Craft distinctive brand identities in seconds. Generate vector-ready logos that balance modern minimalism with timeless design, allowing you to iterate through hundreds of unique variations until you find the perfect face for your business.

Pro YouTube Thumbnail Maker

Skyrocket your CTR with scroll-stopping visuals. Our AI analyzes high-performing niches to generate attention-grabbing layouts, featuring professional-grade backdrop removal, custom typography, and vibrant color grading designed to dominate the homepage.

Manga Studio AI

Breathe life into your stories with professional-grade manga art. From classic Shonen ink-washes to detailed Seinen aesthetics, generate panel-by-panel illustrations with consistent character design and dynamic visual storytelling capabilities.

Viral Reels Generator

Own the short-form landscape with AI-driven video editing. Automatically transform raw footage or ideas into high-energy Reels and TikToks, complete with dynamic transitions, viral hooks, and audio-syncing that perfectly matches the latest trending beats.

Instant Game Engine

Turn prompts into playable reality. Build fully functional HTML5 games—from retro platformers to neon-themed shooters—complete with procedural mechanics, physics, and custom scoring systems, all without writing a single line of code.

AI Music Studio

Transform ideas into broadcast-quality music using Suno V5. Generate full songs with vocals or pure instrumentals, and use the built-in AI isolator to separate tracks with studio precision.

AI Marketing Suite

A powerful new module for automated product visualization and media generation for professional product videos and AI avatars. Create, manage, and deploy AI-generated avatars for brand representation and social media content.

AI Website Builder

Generate fully functional, responsive websites from a single text prompt. Edit them instantly in the browser and see changes in real-time. Features automated subdomain and custom domain mapping served directly from PostgreSQL via Next.js middleware URL rewrites.

Interactive AI Playground

Test your prompts, compare model outputs, and experiment with different parameters in a dedicated sandbox environment. Supports multiple global models side-by-side.

WhatsApp AI Auto-Responder

Automate inbound WhatsApp sales and support chats 24/7. Leverages Baileys sockets with base64 credentials saved directly in PostgreSQL to prevent session loss on Vercel/serverless redeploys. Features SSE QR code streaming, whitelist number targets, and custom reply delays.

Hybrid RAG Document Search Index

Ground your AI's support answers in factual company documents. Parses PDFs, DOCX, and TXT files, chunking them into segments. Embeds texts using Gemini and saves them in pgvector with HNSW indexing. Executes vector cosine similarity matches and falls back to PostgreSQL Full-Text English keyword search.

Technical Trading Terminal

Run a financial metrics portal. Includes real-time Yahoo Finance and CoinGecko quote pipelines, in-memory caches to prevent third-party API blocking, and pure TypeScript math libraries computing SMA, EMA, RSI, MACD, Bollinger Bands, Stochastic RSI, ATR, VWAP, Pivot Points, and candlestick patterns, alongside paper trading portfolios.

Slide Presentation Generator

Draft slide layout structures (PPT Playground) based on plain-text prompt descriptions, edit them inside the interactive dashboard, and export presentation files using the pptxgenjs library.

Role-Based Access Control (RBAC) & Security

Enterprise-grade security and user management built-in:

  • Secure Middleware: Automatic route protection preventing unauthorized access to Admin pages.
  • Feature Gating: Control which tools specific users can access based on their plan or role.
  • Session Management: Secure, token-based authentication using JWT (JOSE) and Cookies.
  • Two-Factor Authentication (2FA): RFC 6238-compliant TOTP algorithms with Base32 serialization and AES-256-GCM encryption at rest, including backup recovery codes.
  • Sliding-Window Rate Limiting: In-memory rate-limiter protecting auth, verification, and database-intensive routes against brute-force attacks.

Frequently Asked Questions (FAQ)

  • Q: How do database migrations work?
    A: Deployed using the raw pg package. Run npm run migrate to execute the runner, reading schema.sql and building your database structures instantly.
  • Q: Are WhatsApp connections lost on Vercel restart?
    A: No. Unlike traditional file systems, AI Suite serializes the Baileys credentials and synchronizes them directly in the whatsapp_sessions table, keeping agents online across deployments.
  • Q: Can I run this with custom models?
    A: Yes. The streaming API endpoint supports Google GenAI, OpenAI, Anthropic, Mistral, Groq, and custom NVIDIA models out-of-the-box.
